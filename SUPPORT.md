# Support

For usage questions, design discussions, and documentation improvements, start a [GitHub Discussion](https://github.com/acefolioDev/elpod/discussions). Search existing discussions before opening a new one and include Bun, Elpod, and Elysia versions plus a minimal reproduction when useful.

For reproducible defects in the repository or published package, open a [bug report](https://github.com/acefolioDev/elpod/issues/new?template=bug_report.yml). Do not use public issues for security vulnerabilities; follow [SECURITY.md](./SECURITY.md).

Feature ideas belong in [feature requests](https://github.com/acefolioDev/elpod/issues/new?template=feature_request.yml) or Discussions first. Please explain the problem and boundary you are trying to solve rather than only proposing an API.
